# AI Agent Guidance

This repository is an existing React, Vite, and TypeScript Airbnb listing page assignment. Continue the current implementation; do not scaffold or replace the application.

## Working rules

- Read `.agents/skills/airbnb-clone/SKILL.md` before changing listing, gallery, or modal behavior.
- Keep edits focused and preserve existing components and interactions.
- Do not copy source code from the reference website. Use it only for visual and behavior comparison when it is available.
- For photo flows, verify hero photo clicks, Photo Tour entry and exit, lightbox index, previous/next controls, Left/Right, Escape, and keyboard focus behavior.
- Keep `README.md`, `PROMPTS.md`, and `ARCHITECTURE.md` aligned with the implementation.
- Run `npm run build` for final production compilation verification.
